# 🥗 개인 맞춤 식단 관리 프로그램

사용자의 **신체 정보와 식단 데이터를 기반으로 탄수화물·단백질·지방 비율을 분석하고, 부족한 영양소를 보완할 수 있는 음식을 추천하는 Java Console 프로젝트**입니다.

식품 영양 정보는 코드에 직접 입력하지 않고 CSV 파일에서 불러오며, 사용자가 입력한 음식명을 기반으로 실제 식품 데이터를 검색합니다.

또한 단순 CRUD 기능에 그치지 않고, 학습한 알고리즘을 활용하여 사용자의 목표 탄단지 비율에 가까워질 수 있는 음식 조합을 탐색하는 것을 목표로 합니다.

---

## 📌 주요 기능

### 1. 회원 관리

사용자는 회원가입을 통해 자신의 기본 신체 정보를 등록할 수 있습니다.

* 회원가입
* 로그인
* 로그아웃
* 회원정보 조회
* 회원정보 수정
* 회원 탈퇴
* 키 / 몸무게 저장

회원가입 시 저장한 키와 몸무게는 이후 BMI 및 식단 분석에 활용됩니다.

---

### 2. 음식 데이터 조회

식품 영양 정보는 `rawData.csv` 파일에서 읽어옵니다.

각 음식은 다음 정보를 가지고 있습니다.

```text
foodId
foodName
kcal
protein
fat
carbo
sugar
```

프로그램 실행 시

```text
rawData.csv
        ↓
FoodCsvReader
        ↓
List<Food>
        ↓
FoodRepository
```

순서로 음식 데이터를 불러옵니다.

사용자가 다음과 같이 입력하면

```text
김밥,계란,고구마
```

`FoodRepository`가 CSV에서 읽어온 전체 음식 중 입력한 이름과 일치하는 `Food` 객체를 검색합니다.

## 🍱 식단 관리

로그인한 사용자는 자신의 식단을 관리할 수 있습니다.

### 식단 등록

```text
식단 이름: 아침 식단
음식 이름: 계란,고구마,우유
```

### 식단 조회

등록한 식단의 음식과 탄단지 비율을 확인할 수 있습니다.

### 식단 수정

식단 이름이나 포함된 음식을 변경할 수 있습니다.

### 식단 삭제

등록한 식단을 삭제할 수 있습니다.

각 사용자의 식단은 별도로 관리됩니다.

# 📊 식단 분석

사용자가 실제로 먹은 음식을 입력하면 식단의 탄수화물, 단백질, 지방을 분석합니다.

예:

```text
먹은 음식 이름:
김밥,계란,닭가슴살
```

음식별 영양성분을 모두 합산한 후 탄단지의 열량 비율을 계산합니다.

탄수화물과 단백질은 `1g당 4kcal`, 지방은 `1g당 9kcal`로 계산합니다.

```text
탄수화물 kcal = 탄수화물(g) × 4
단백질 kcal   = 단백질(g) × 4
지방 kcal     = 지방(g) × 9
```

이후 전체 열량 중 각각이 차지하는 비율을 계산합니다.

```text
탄수화물 비율
= 탄수화물 kcal / 탄단지 총 kcal × 100

단백질 비율
= 단백질 kcal / 탄단지 총 kcal × 100

지방 비율
= 지방 kcal / 탄단지 총 kcal × 100
```

---

# 👤 BMI 기반 목표 비율

회원가입 시 저장된

```text
키
몸무게
```

를 이용하여 BMI를 계산합니다.

```text
BMI = 몸무게(kg) / 키(m)²
```

계산된 BMI에 따라 프로그램 내부 정책에서 목표 탄단지 비율을 결정합니다.

```text
회원정보
키 + 몸무게
      ↓
BMI 계산
      ↓
목표 탄단지 비율
```

> BMI별 목표 탄단지 비율은 공식적인 BMI별 영양 기준이 아니라 프로젝트에서 정의한 추천 정책입니다.

---

# 🔍 현재 식단과 목표 비교

예를 들어 사용자의 목표 비율이

```text
탄수화물 50%
단백질   30%
지방     20%
```

이고 현재 식단이

```text
탄수화물 35%
단백질   40%
지방     25%
```

라면 각 영양소의 차이를 계산합니다.

```text
탄수화물 → 부족
단백질   → 과다
지방     → 과다
```

이를 통해 어떤 영양소를 보완해야 하는지 확인할 수 있습니다.

---

# 🤖 음식 추천 알고리즘

현재 식단이 목표 탄단지 비율과 차이가 있을 경우 추가로 먹을 음식을 추천합니다.

전체 음식 데이터를 그대로 조합하면 경우의 수가 매우 많아질 수 있기 때문에 다음과 같은 구조로 추천 기능을 구성합니다.

```text
현재 식단
        ↓
현재 탄단지 계산
        ↓
목표 탄단지와 비교
        ↓
부족한 영양소 확인
        ↓
추천 후보 음식 선정
        ↓
DFS + Backtracking
        ↓
가장 목표 비율과 가까운 조합 탐색
```

---

## DFS + Backtracking

후보 음식마다 두 가지 선택을 수행합니다.

```text
현재 음식 선택
현재 음식 선택하지 않음
```

예를 들어 후보 음식이

```text
닭가슴살
고구마
계란
바나나
```

라면 다음과 같은 형태로 탐색합니다.

```text
닭가슴살
├── 선택
│   ├── 고구마 선택
│   └── 고구마 미선택
│
└── 미선택
    ├── 고구마 선택
    └── 고구마 미선택
```

추천 음식은 최대 3개까지 선택하도록 제한합니다.

또한 추천 음식을 추가한 뒤 사용자가 설정한 최대 칼로리를 초과하면 더 이상 해당 조합을 탐색하지 않습니다.

```text
현재 총 칼로리 > 최대 칼로리
        ↓
return
```

이를 통해 불필요한 탐색을 줄입니다.

---

## 목표와의 차이 계산

각 음식 조합을 선택한 뒤 새로운 탄단지 비율을 계산합니다.

목표 비율과 현재 비율의 차이는 다음과 같이 계산할 수 있습니다.

```text
difference

= |목표 탄수화물 - 현재 탄수화물|
+ |목표 단백질 - 현재 단백질|
+ |목표 지방 - 현재 지방|
```

`difference`가 작을수록 목표 탄단지 비율에 가까운 식단입니다.

따라서 탐색한 조합 중 가장 작은 `difference`를 가지는 음식 조합을 최종 추천합니다.

```text
먹은 음식 이름:
```
